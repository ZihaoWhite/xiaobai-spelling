# 小白拼写产品规格

## 1. 产品定位

小白拼写服务于每天从其他背词软件导出 CSV 的个人学习流程。核心行为是“看、听、完整输入、核对”，通过重复输入建立字母顺序记忆和键盘肌肉记忆。

产品体验关键词：现代、温和、专注、轻快。主界面每次只呈现一个单词，不把应用做成表格后台。

## 2. 数据边界

应用只发现以下位置的非隐藏、非临时 CSV：

- 项目根目录
- `vocabulary_data/`
- `uploaded_csv/`

`.backups/` 不参与扫描。启动和普通交互只保留当前 DataFrame；历史 CSV 只扫描元数据，不预读取、不合并。

必要字段为：

```text
单词, 中文释义, 类型, 当前状态, 当天答题次数, 当天正确, 当天错误
```

读取依次尝试 `utf-8-sig`、`utf-8`、`gb18030`。字符串列去除首尾空格，数值列安全转换为整数，空单词行不进入队列。DataFrame 原始行索引是当前会话中的题目 ID，因此重复单词也会分别计分。

## 3. 文件发现与选择

文件顺序：

1. 文件名含 `export` 的文件优先；
2. 同组按最后修改时间从新到旧；
3. 首个文件作为默认选择。

下拉标签优先展示文件名中的日期。同名文件同时出现时补充父目录。刷新文件列表只更新元数据；当前文件仍存在时不重载、不洗牌、不重置进度。

上传文件先取安全基础文件名，再写入 `uploaded_csv/` 的临时文件。临时副本通过字段与编码验证后才原子替换目标文件；失败不会影响当前练习。

## 4. 练习队列

首次加载、切换文件、重新开始、再来一轮和只练本轮错题时才新建队列。普通 rerun 不重排。

普通队列先分为：

- `当天错误 > 0`
- `当天错误 == 0`

两组分别随机打乱，再将错词组放在前面。队列只保存行索引，不复制整行。

## 5. 三种模式

- 模式 A：显示完整英文、中文、词性、类型和发音，适合肌肉跟打。
- 模式 B：隐藏英文，只显示首尾字符与中间占位符。连字符和撇号保留，因为判断时也不会忽略它们。
- 模式 C：只显示中文、词性、类型和发音，进行盲拼。

模式切换只改变当前卡片展示，不改变队列、题号、统计或输入状态。

## 6. 答题状态机

每题流程：

1. 进入新题，尝试一次自动播放并自动聚焦拼写输入框；
2. 用户无需点击输入框，直接输入并按 Enter；
3. 空答案显示提醒，不计分；
4. 有效答案先更新内存，再安全保存；
5. 保存成功才将当前题标记为已答；
6. 保存成功后立即进入下一题，并自动聚焦新的输入框；
7. 下一题上方显示上一题轻量反馈，错误时保留逐字符核对；
8. 一次 Enter 只处理一次答题，不重复计分；
9. 最后一题提交后直接进入完成页。

答案标准化只做首尾去空格和 `casefold()`。内部空格、连字符、撇号均保留，不自动修复拼写。

字符核对使用 `difflib.SequenceMatcher` 进行序列对齐，区分正确、替换、漏写和多写。所有写入自定义 HTML 的 CSV 与输入内容均先经过转义。

## 7. 写回与备份

每次有效提交：

- `当天答题次数 += 1`
- 正确则 `当天正确 += 1`
- 错误则 `当天错误 += 1`
- `当前状态` 不修改

更新严格使用当前题的 DataFrame 行索引。

首次修改当前源文件前，在 `.backups/` 创建一次时间戳备份。保存采用 UTF-8 BOM、`index=False`，先在源文件同目录写临时文件并刷盘，再通过 `os.replace()` 原子替换。失败时回滚本题内存计数和本轮统计，允许重新提交。

## 8. 本轮统计与完成页

本轮数据独立于 CSV 累计列维护：

- 已答数
- 正确数
- 错误数
- 本轮错题记录

完成后每轮只触发一次庆祝效果，展示正确率与本轮错题。错题表不从 CSV 历史错误列推断。用户可以再来一轮、只练本轮错题，或下载当前内存中的最新 CSV。

## 9. 性能与异常

- 普通 rerun 不扫描目录、不读取 CSV、不重建队列。
- 每次只渲染当前题的卡片、音频、输入和 diff。
- 文件为空、字段缺失、编码错误、上传失败和保存失败均显示中文提示。
- 当前文件被删除后保留内存 DataFrame，并提供下载入口。
- 发音服务或浏览器自动播放失败不阻断答题。

## 10. 验收

最低验收命令：

```bash
python -m compileall app.py
pytest -q
streamlit run app.py
```

浏览器验收至少覆盖：无 CSV 欢迎页、CSV 加载、三种模式、空答案、正确与错误反馈、下一题、最后一题、错题复练、备份生成和 CSV 写回。
